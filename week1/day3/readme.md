# Day 03 – Understanding Tokens & Token Usage in LLMs

## 🎯 Objective

Understand what tokens are, how LLMs process text in the form of tokens, how token consumption is measured, and how output token limits affect generated responses.

## 📚 Concepts Learned

### 1. What Are Tokens?

Tokens are the basic units of text processed by a Large Language Model.

An LLM does not directly process human-readable sentences as we see them. Text is first converted into tokens, which are then mapped to numerical token IDs.

A token can represent:
- A complete word.
- A part of a word.
- A punctuation mark.
- Whitespace or other text elements.

**Example:**

```text
Input: "I love Artificial Intelligence!"

Possible token representation:
["I", " love", " Artificial", " Intelligence", "!"]
```

*This is an illustrative example; actual tokenization depends on the tokenizer.*

### 2. Prompt Tokens

Prompt tokens represent the tokens consumed by the input sent to the model.

For example:

```python
usage = response.usage
print(usage.prompt_tokens)
```

These tokens generally include the input messages and their associated formatting.

### 3. Completion Tokens

Completion tokens represent the tokens generated by the model in its response.

```python
print(usage.completion_tokens)
```

The number of completion tokens depends on the generated response and the output limit.

### 4. Total Tokens

Total tokens represent the combined input and output token consumption.

```python
print(usage.total_tokens)
```

Formula:

**Total Tokens = Prompt Tokens + Completion Tokens**

### 5. Understanding max_tokens

`max_tokens` specifies the maximum number of output tokens that the model can generate for a completion.

Example:

```python
response = client.chat.completions.create(
    model=model,
    messages=messages,
    max_tokens=50
)
```

Here, the model is limited to generating at most 50 completion tokens.

**Important observations:**
- A smaller output limit can produce shorter responses.
- A larger output limit allows longer responses.
- The model may stop before reaching the limit.
- If the output limit is reached, the response may be truncated.

### 6. Finish Reason

The `finish_reason` field indicates why the model stopped generating a response.

```python
response.choices[0].finish_reason
```

Common finish reasons include:

| Finish Reason | Meaning |
|---|---|
| `stop` | Model finished naturally |
| `length` | Output token limit was reached |
| `tool_calls` | Model requested a tool call |

The exact values depend on the API and model.

## 💻 Practical Implementation

Implemented a Python program using the Groq API to experiment with different prompt lengths and observe token consumption.

**Experimented with three prompts:**

1. `Hi!!` – Short conversational prompt.
2. `Explain time travel in detail` – Descriptive prompt.
3. `Write a 1000 word essay on machine learning` – Long-form generation request.

For each prompt, the implementation:
- Creates a user message.
- Sends the request to the LLM.
- Sets `max_tokens=50`.
- Extracts prompt token usage.
- Extracts completion token usage.
- Checks the finish reason.
- Displays the generated response.

**Important code snippet:**

```python
usage = response.usage

print(
    f"Prompt Tokens: {usage.prompt_tokens}, "
    f"Completion Tokens: {usage.completion_tokens}, "
    f"Finish Reason: {response.choices[0].finish_reason}"
)
```

## 🔍 Key Observations

- Different prompts consume different numbers of input tokens.
- Longer prompts generally require more prompt tokens.
- Generated responses consume completion tokens.
- `max_tokens` restricts the maximum output length.
- A request for a 1000-word essay may return a much shorter response when the output limit is only 50 tokens.

## 💡 Key Takeaways

- Tokens are the fundamental units of text processed by LLMs.
- Prompt tokens measure input consumption.
- Completion tokens measure generated output consumption.
- Total tokens combine input and output consumption.
- Output token limits help control response length and resource usage.
- Finish reasons help identify why generation stopped.
